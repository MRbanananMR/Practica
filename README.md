# Social App

Простое веб-приложение, в котором пользователи могут:
- зарегистрироваться;
- войти в систему;
- публиковать посты;
- видеть посты всех пользователей в общей ленте.

## Технологии
- Python
- Flask
- SQLite

## Запуск
1. Установите зависимости:
   python -m pip install -r requirements.txt
2. Запустите приложение:
   python app.py
3. Откройте в браузере:
   http://127.0.0.1:5000

## Структура проекта
- app.py — основной код приложения
- templates/ — HTML-шаблоны
- static/ — стили
- instance/social.db — SQLite-база данных

## Основная идея
Каждый пост сохраняется в общей базе данных, поэтому все пользователи видят одну и ту же ленту.

## Дополнительно
В репозитории соблюдается шаговая история изменений и ветвление: main, feature/auth, feature/feed и т.д.
